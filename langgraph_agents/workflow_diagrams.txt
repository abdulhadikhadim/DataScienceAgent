## 5. Node Connections Summary

### Basic Workflow Nodes:
1. START → Data Loader
2. Data Loader → Anomaly Detector
3. Anomaly Detector → Anomaly Handler (if anomalies)
4. Anomaly Detector → Null Detector (if no anomalies)
5. Anomaly Handler → Null Detector
6. Null Detector → Null Handler (if nulls)
7. Null Detector → Feature Processor (if no nulls)
8. Null Handler → Feature Processor
9. Feature Processor → Validator
10. Validator → END (if passed)
11. Validator → Retry Decision (if failed)
12. Retry Decision → Anomaly Detector (retry)
13. Retry Decision → END (max iterations)

### Enhanced Workflow Nodes:
1. START → Data Loader
2. Data Loader → Schema Validator
3. Schema Validator → Schema Enforcer (if invalid)
4. Schema Validator → Type Caster (if valid)
5. Schema Enforcer → Type Caster
6. Type Caster → Format Normalizer
7. Format Normalizer → Encoding Standardizer
8. Encoding Standardizer → Integrity Checker
9. Integrity Checker → Anomaly Detector
10. Anomaly Detector → Anomaly Handler (if anomalies)
11. Anomaly Detector → Null Detector (if no anomalies)
12. Anomaly Handler → Null Detector
13. Null Detector → Null Handler (if nulls)
14. Null Detector → Quality Rules (if no nulls)
15. Null Handler → Quality Rules
16. Quality Rules → Deduplicator
17. Deduplicator → Feature Processor
18. Feature Processor → Validator
19. Validator → END (if passed)
20. Validator → Retry Decision (if failed)
21. Retry Decision → Anomaly Detector (retry)
22. Retry Decision → END (max iterations)

## 6. Conditional Routing Logic

### After Schema Validation:
```python
if schema_validation_result['valid']:
    goto("cast_types")
else:
    goto("enforce_schema")
```

### After Anomaly Detection:
```python
if len(anomalies_detected) > 0:
    goto("handle_anomalies")
else:
    goto("detect_nulls")
```

### After Null Detection:
```python
if len(null_values_info) > 0:
    goto("handle_nulls")
else:
    goto("apply_quality_rules")
```

### After Validation:
```python
if validation_passed:
    goto(END)
elif iteration_count < max_iterations:
    goto("retry_decision")
else:
    goto(END)
```

## 7. Feedback Loop Mechanism

```
Iteration 1:
  Anomaly Detector → Anomaly Handler (cap) → ... → Validator (FAIL)
    ↓
  Retry Decision: Switch to "flag" strategy
    ↓
Iteration 2:
  Anomaly Detector → Anomaly Handler (flag) → ... → Validator (FAIL)
    ↓
  Retry Decision: Switch to "median" for nulls
    ↓
Iteration 3:
  Anomaly Detector → Anomaly Handler (flag) → ... → Validator (PASS)
    ↓
  END
```

## 8. Agent Dependencies

### Parallel Execution Groups:
- **Group 1 (Can run in parallel):**
  - Type Casting
  - Format Normalization
  - Encoding Standardization

- **Group 2 (Sequential dependencies):**
  - Schema Validation → Schema Enforcer
  - Anomaly Detection → Anomaly Handling
  - Null Detection → Null Handling

- **Group 3 (Final processing):**
  - Quality Rules → Deduplication → Feature Processing → Validation

## 9. Error Handling Flow

```
Agent Error
    ↓
Log Error Message
    ↓
Update State with Error
    ↓
Continue to Next Agent (if non-fatal)
    ↓
OR
    ↓
Stop Workflow (if fatal)
    ↓
Return Error State
```
